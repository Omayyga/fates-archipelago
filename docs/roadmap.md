# Roadmap

## >> Phase 1 — Design data

Create draft data files for:

- Revelation locations
- Fates item pool
- YAML/options
- logic notes

## >> Phase 2 — Minimal APWorld skeleton

Create a custom Archipelago world that can generate a seed with placeholder Fates items and locations.

## >> Phase 3 — Manual playtest

Use manual check sending to test whether the ruleset is fun before deep automation.

## >> Phase 4 — Randomizer integration

Fork or integrate with an existing Fire Emblem Fates randomizer.

Patch goals:

- randomized units
- randomized starting weapons
- AP chest vouchers
- AP shop vouchers
- guaranteed Master Seal access
- guaranteed chest access

## >> Phase 5 — Fates AP client

Build a client that can:

- connect to Archipelago
- send checks
- receive Fates items
- queue item rewards safely
- handle release after goal completion

## >> Phase 6 — Automation research

Investigate:

- chapter completion detection
- chest/shop voucher detection
- recruitment detection
- convoy/item injection
- unit defeat detection
- DeathLink unit defeat application
